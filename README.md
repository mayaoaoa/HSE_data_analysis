### `final project`
итоговый проект по курсу, содержит предварительную обработку данных, EDA, проверку гипотез, построение моделей линейной регрессии и кластеризации, и презентацию

-----------------
Прочие выполненные задания по курсу:

`statistic test` – проверка гипотезы о равенстве средних с помощью статистических критериев

`statistic description` – математическое описание данных и оценка взаимосвязей параметров, анализ на выбросы

`superstore`, `superstore2`, `netflix` – работа с методами обработки и агрегирования данных

`plotly`, `seaborn` – работа с библиотеками для визуализации

`linear`, `kmeans` – построение моделей линейной регрессии и кластеризации
