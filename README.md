`final project` – итоговый проект по курсу, содержит предварительную обработку данных, EDA, проверку гипотез, построение моделей линейной регресси и кластеризации, а также презентацию

`statistic test` – проверка гипотезы о равенстве средних с помощью статистических критериев и проверка соответствия им

`statistic description` – математическое описание данных и оценка взаимосвязей параметров (метрических и неметрических), анализ на выбросы

`superstore`, `superstore2`, `netflix` – работа с методами обработки и агрегирования данных в pandas

`plotly`, `seaborn` – работа с библиотеками для визуализации

`linear`, `kmeans` – построение моделей линейной регрессии и кластеризации
